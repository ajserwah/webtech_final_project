# AmaDialogue

Inspector Ama's speech card: her pixel portrait beside one line from the case script, on a light card.

- Ama always speaks from a light card, so her voice reads apart from the dark tools.
- One line at a time, word for word from the script. Back and Next step through a sequence.
- Her portrait tile uses `panel-raised`, never a suspect colour.
- Text only for now. If the group adds voice, the card gets a play control and the text stays.
