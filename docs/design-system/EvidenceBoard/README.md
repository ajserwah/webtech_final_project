# EvidenceBoard

The crime-board kit: exhibit cards pinned on a red thread, keycap step numbers, and the CASE CLOSED stamp.

- Used on the home page ("How a case plays"), the crime board, and the case-closed moment.
- `evidence-red` is for the thread, pins and stamp only. It never means "error".
- Exhibits tilt slightly and alternate direction (-1.2°, 1°, -0.8°). Never more than 2°.
- The stamp appears once, at the moment a case closes. Don't use it as decoration elsewhere.
