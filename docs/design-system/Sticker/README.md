# Sticker

A tilted orange label pinned to the corner of a panel or button: the one playful line on a screen.

- Exactly one per screen, or none.
- Lowercase, three or four words, no full stop: "start here", "never drawn on screen", "who posted this?".
- It comments on the thing it's stuck to. It never carries instructions the player needs.
- Position it absolutely from the parent's top-right corner (the parent needs `position: relative`).
