# Suspect

A suspect shown as a chip (in the notebook and crime board) or a row (on the case file), filled with that suspect's colour.

**The colour rule**
- Suspects take `suspect-1` to `suspect-4` in the order the case script lists them.
- That colour follows the suspect on every screen: case file, chips, notebook, crime board, accusation.
- Nothing else in the game uses these four colours, not even Ama.

**Content**
- Chip: first name and handle. Row: full name, role, handle.
- Motives are not shown here; the case decides whether the player learns them.
