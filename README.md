# Case Closed

An interactive detective game that teaches web development concepts through solving mysteries.

## Installation

Install the project dependencies:

```bash
npm install
```

## Running the Project

Start both servers:

```bash
npm run dev
```

## Local Development URLs

- **Game Origin:** http://localhost:3000
- **Sites Origin:** http://localhost:3001

The game origin serves the main detective game homepage, while the sites origin serves the placeholder case website.
